# Real-Time Currency Converter

A lightweight Python command-line tool that communicates with a public Exchange Rate API to perform real-time currency conversions. This project showcases proficiency in working with HTTP requests, handling JSON data structures, and managing API responses in Python.

## Features
* **Live Exchange Rates:** Pulls up-to-date economic data directly from a public financial API.
* **Dynamic Conversion:** Easily converts numerical figures across global currencies (e.g., USD, EUR, GBP).
* **Error Handling:** Built-in exceptions to handle internet connectivity issues safely.

## Requirements
* Python 3
* An active internet connection (to fetch live API data)

## How to Run
Execute the script using:
```bash
python converter.py
```
